# 🦎 Casta Exotics

Proyecto escolar de desarrollo web que simula una plataforma de comercio electrónico especializada en la exhibición y venta responsable de animales exóticos. Permite a los usuarios explorar distintas especies, conocer sus cuidados básicos y gestionar un carrito de compras interactivo.

##  Características principales
* **Catálogo interactivo:** Visualización de ejemplares organizados por categorías (reptiles, anfibios, artrópodos, etc.).
* **Fichas informativas:** Detalles clave sobre hábitat, alimentación, temperatura y nivel de experiencia requerido para cada especie.
* **Carrito de compras dinámico:** Funcionalidad desarrollada con JavaScript para agregar productos, actualizar cantidades y calcular el total en tiempo real.
* **Diseño responsivo:** Interfaz adaptable a dispositivos móviles y computadoras de escritorio.

##  Tecnologías y herramientas
* **HTML5:** Estructura semántica de las páginas.
* **CSS3:** Estilos, diseño visual y responsividad.
* **JavaScript (Vanilla):** Lógica del carrito de compras, filtros e interactividad del sitio.
* **VS Code:** Entorno de desarrollo utilizado para la codificación.
